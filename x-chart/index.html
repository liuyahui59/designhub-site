02 / 插件功能

从找到图表，
到放进 Sketch。

创建、编辑和模板不是三个孤立页面，而是同一套图表资产在不同任务里的入口。

01 / SELECT

按场景选择

从趋势、对比、占比等使用目的出发，快速定位主图表和变体。

场景 → 图表 → 变体
02 / DATA

自由接入数据

支持手动表格、CSV、本地 JSON 与 HTTPS JSON，预览随数据同步更新。

TABLE · CSV · JSON
03 / STYLE

精细控制样式

调整色板、字体、标签、网格、线条、间距与图表族专属参数。

TOKEN · AXIS · LABEL
04 / REUSE

模板持续复用

为不同项目建立图表模板，并决定图表跟随模板或保留独立样式。

LINKED · FROZEN · DETACHED

03 / 搭建思路

自由组合的背后，
是一套统一的图表中台。

数据、图表组件和全局样式分别管理，再由一个公共核心完成规范化与几何计算。一处修改，可以作用到创建、编辑、模板和最终 Sketch 产物。
