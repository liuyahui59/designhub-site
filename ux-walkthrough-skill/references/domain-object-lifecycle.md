# 对象生命周期、状态流转与权限

> 触发：存在创建、编辑、提交、审批、发布、撤回、归档、删除、权限变更，或对象具有两个以上业务状态。

执行前枚举对象状态、角色和关键状态流转，建立 `角色 × 状态 × 操作` 矩阵。

### LIFE-01 状态模型完整

检查对象状态、起点、终点、合法转移与终止状态是否明确，不能只检查当前页面出现的状态。

### LIFE-02 角色、状态与操作匹配

检查每个角色在每个状态下应可见、可执行和禁止的操作；识别有权限无入口、无权限有入口、前后端权限不一致。

### LIFE-03 状态流转可理解

检查当前状态、操作结果、目标状态、责任人和下一步是否明确，跨列表、详情和操作区术语一致。

### LIFE-04 动作闭环与下游同步

验证入口、条件、操作、进行中、结果、状态变化，以及列表、详情、数量、操作区和下游任务同步。

### LIFE-05 异常、部分成功与恢复

验证接口失败、重复点击、部分成功、混合状态批量对象、权限变化和通知失败；保护输入并提供安全重试。

### LIFE-06 并发与数据新鲜度

检查更新时间、他人修改、保存覆盖、过期状态、刷新后的上下文和冲突后的比较与恢复。

### LIFE-07 撤销、撤回与不可逆操作

检查高风险操作的确认、影响说明、撤回、恢复和不可逆边界；是否二次确认取决于风险与项目规范，不作通用硬规则。

### LIFE-08 审计与可追溯

检查谁在何时执行什么操作、状态前后值、原因、批量结果和自动化操作是否可找到、理解并与当前状态一致。

## 完成标准

- 关键状态、角色和流转已枚举。
- 核心流转已验证成功、失败和恢复中的适用场景。
- 列表、详情、状态和操作区一致性已检查。
- 未验证流转进入 coverage 的 `not_tested / blocked`，不伪装为通过。
